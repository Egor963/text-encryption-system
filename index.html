🔐 Система шифрования текста

Шифр Цезаря · Шифр Виженера · XOR-шифр — JavaScript

Шифр Цезаря — моноалфавитный шифр подстановки. Каждая буква алфавита заменяется буквой, стоящей на N позиций дальше (или ближе) в алфавите. Буквы за пределами алфавита переносятся циклически. Небуквенные символы не изменяются.
Шифр Виженера — полиалфавитный шифр. Использует ключевое слово: каждая буква ключа задаёт величину сдвига для соответствующей буквы текста. Ключ повторяется циклически. Небуквенные символы пропускаются без изменений.
XOR-шифр — симметричный шифр. Каждый символ текста обрабатывается операцией «исключающее ИЛИ» с соответствующим символом ключа (ключ повторяется циклически). Результат кодируется в Base64 для удобного отображения и хранения. Применение алгоритма дважды восстанавливает исходный текст.
