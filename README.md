# Система шифрования

Учебное веб-приложение для шифрования и дешифрования текста на JavaScript.

Поддерживает:

- шифр Цезаря для латиницы и кириллицы;
- шифр Виженера для латиницы и кириллицы;
- XOR-шифрование с выводом результата в hex.

## Запуск

Откройте `index.html` в браузере. Установка зависимостей и сборка не требуются.

Для запуска автоматических проверок:

```bash
npm test
```

## Файлы проекта

- `index.html` - интерфейс;
- `styles.css` - оформление;
- `app.js` - логика интерфейса;
- `encryption.js` - алгоритмы шифрования;
- `test.js` - автоматические проверки.

> Проект создан в учебных целях. Эти алгоритмы не следует использовать для защиты реальных конфиденциальных данных.
