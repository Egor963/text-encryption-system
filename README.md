# Система шифрования текста

Учебное веб-приложение для шифрования и расшифрования текста на JavaScript.

Поддерживает три алгоритма:

- шифр Цезаря;
- шифр Виженера;
- XOR-шифрование с представлением результата в Base64.

## Запуск

Откройте `index.html` в браузере. Установка зависимостей и сборка не требуются.

Для проверки алгоритмов из командной строки:

```bash
npm test
npm start
```

## Структура

- `index.html` - интерфейс приложения;
- `caesar.js` - шифр Цезаря;
- `vigenere.js` - шифр Виженера;
- `xor.js` - XOR-шифрование;
- `main.js` - демонстрация работы алгоритмов;
- `test.js` - автоматические проверки.

> Проект создан в учебных целях. Классические шифры и простой XOR не предназначены для защиты реальных конфиденциальных данных.
